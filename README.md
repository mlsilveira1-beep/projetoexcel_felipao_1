# projetoexcel_felipao_1
Projeto Desafio Curso Excel Plataforma Dio
Esse projeto cria uma planilha Excel com cara de aplicativo, que responda às cinco perguntas de negócio levantadas antes de abrir o Excel:
Quanto investir por mês;
Por quantos anos;
Qual a taxa de rendimento mensal;
Quanto de patrimônio vai acumular;
Quanto vai receber de dividendos por mês.
Ela também projeta o patrimônio em cenários de 2 a 30 anos e divide o aporte entre três tipos de aplicações financeiras, conforme o perfil de investidor escolhido numa lista.
